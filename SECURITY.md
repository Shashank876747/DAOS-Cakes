# Security Policy

## Supported Versions

We actively update and support the main branch of DAOS Cakes.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security of DAOS Cakes seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do not create a public issue** or disclose the vulnerability publicly.
2. Email the maintainer directly at `daosflorida@gmail.com` with full details of the vulnerability, steps to reproduce, and any relevant proof-of-concept code.
3. You will receive an acknowledgment within 24–48 hours.
4. We will work to resolve the vulnerability as quickly as possible and notify you once a fix has been deployed.

Thank you for helping keep DAOS Cakes safe!
