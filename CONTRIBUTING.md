# Contributing to DAOS Cakes

Thank you for your interest in contributing to **DAOS Cakes**!

## Code of Conduct
We are committed to providing a welcoming, inclusive, and harassment-free environment for all contributors.

## How to Contribute

1. **Fork & Clone**
   - Fork the repo on GitHub.
   - Clone your fork locally:
     ```bash
     git clone https://github.com/<your-username>/DAOS-Cakes.git
     cd DAOS-Cakes
     ```

2. **Branching Strategy**
   - Create a feature branch:
     ```bash
     git checkout -b feature/my-cool-feature
     ```

3. **Development**
   - Install dependencies: `npm install`
   - Run dev server: `npm run dev`
   - Check types and linting: `npm run lint`
   - Verify build: `npm run build`

4. **Submitting Changes**
   - Push your branch to GitHub.
   - Open a Pull Request against `main`.
   - Complete the Pull Request template checklist.
