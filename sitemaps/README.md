# Sitemaps for DAO'S Cakes Florida

This folder contains separate, domain-specific `sitemap.xml` files for each deployment target.

## Directory Structure:
1. `firebase/sitemap.xml` -> For `https://daos---cakes.firebaseapp.com/` (and `https://daos---cakes.web.app/`)
2. `netlify/sitemap.xml` -> For `https://daoscakes.netlify.app/`
3. `pages/sitemap.xml` -> For `https://daoscakes.pages.dev/`

## Deployment & Hosting:
These are also published to the live root public directory for direct URL access:
- `https://daos---cakes.firebaseapp.com/sitemaps/firebase/sitemap.xml` (also at `/sitemap.xml`)
- `https://daos---cakes.firebaseapp.com/sitemaps/netlify/sitemap.xml` (also at `/sitemap-netlify.xml`)
- `https://daos---cakes.firebaseapp.com/sitemaps/pages/sitemap.xml` (also at `/sitemap-pages.xml`)
